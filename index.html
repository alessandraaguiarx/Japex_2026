Sobre o projeto

Aplicação da Álgebra Linear

O projeto demonstra a aplicação de conceitos de Álgebra Linear em um problema relacionado à Engenharia Civil: a determinação do quantitativo de materiais a partir das áreas de alvenaria convencional e estrutural.

Proposta

As relações de consumo são organizadas em uma matriz de coeficientes. Assim, uma única operação matricial relaciona as áreas da obra aos quantitativos de argamassa X, argamassa Y e graute.

Ideia central: transformar dados da obra em quantitativos de materiais por meio de uma transformação linear.

Modelo matemático

Equação matricial

M = A · X

A representa a matriz de consumo; X representa o vetor das áreas da obra; M representa o vetor dos quantitativos de materiais.

Matriz de consumo A

[ 0   3 ]
[ 0   2 ]

Coeficientes → consumo por m²

Sistema linear equivalente 

5x + 0y = Argamassa X

05

Conceitos de Álgebra Linear

Transformação linear

Uma transformação linear é uma função que preserva a soma de vetores e a multiplicação por escalar.

T(x,y) = A · [x ; y]

R² → R³

Vetor das áreas → vetor dos materiais

Espaço vetorial

O modelo utiliza um vetor de entrada pertencente a R² e produz um vetor de saída pertencente a R³.

R² → R³

Entrada: vetor das áreas da obra.

Saída: vetor de materiais.

Combinação linear

As colunas da matriz podem ser interpretadas como vetores:

V₁ = [5 ; 0 ; 0]     V₂ = [0 ; 3 ; 2]
M = xV₁ + yV₂

Para x = 10 e y = 20, o vetor final é: [50 ; 60 ; 40].
